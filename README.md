AnalystLab Africa – Week 2 Business Intelligence Dashboard
Project Overview

This project was completed as part of the AnalystLab Africa Data Analytics Internship Programme – Week 2.

The project focuses on using Microsoft Power BI to analyse a Superstore sales dataset and develop an interactive Business Intelligence dashboard for supporting data-driven business decisions.

Business Objective

The main objective of this project is to analyse sales and profitability performance and identify high- and low-performing products, regions, categories, and customer segments.

The dashboard helps provide insights that can support better business decisions and improve overall profitability.

Tools Used
Microsoft Power BI
Power Query
DAX
GitHub
Microsoft Excel/CSV
Data Preparation

The dataset was prepared using Power Query in Power BI. The preparation process included:

Importing the dataset
Reviewing the dataset structure
Checking for missing values
Removing duplicate records where necessary
Correcting inappropriate data types
Performing basic data cleaning and transformation
Dashboard Features

The Power BI dashboard includes:

Total Sales
Total Profit
Total Orders
Average Sales
Profit Margin
Sales trends
Sales and profit by region
Product profitability analysis
Top-performing products
Bottom-performing products
Interactive slicers for Region, Category, Segment, and Ship Mode
Business Insights

The dashboard was used to identify:

Differences in sales and profitability between regions.
Differences in profitability across products.
Differences in performance between product categories.
Changes in sales performance over time.
Differences in contribution between customer segments.

The analysis also identified business risks and opportunities related to low-profit products, regional performance, and customer segments.

Business Recommendations

Based on the dashboard analysis, the key recommendations include:

Promote high-profit products.
Review low- and negative-profit products.
Develop region-specific business strategies.
Focus marketing on valuable customer segments.
Monitor profit alongside sales when evaluating performance.

Conclusion

This project demonstrates how Business Intelligence and Power BI can transform business data into meaningful visual insights. The dashboard provides an interactive view of sales and profitability performance and supports evidence-based decision-making.
